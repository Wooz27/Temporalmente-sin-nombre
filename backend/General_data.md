A ver hay 2 carpetas madres el backend hecho con django y frontend con astro

Django esta pensado para crear el panel admin y la api

Astro al ser server render lo prefiero para el frontend para mejorar el seo.

Para el despliegue va directo con un yaml automatica y en el env del yam se ponen los datos para crear el auth de django
